## 🔄 CONTINUOUS EXTRACTION CYCLE

Cycle Pattern (Repeats Infinitely):
1. Shuffle 135 cities
2. For each city:
   - Shuffle 108 categories
   - For each category:
     * Direct scraping (JustDial, TradeIndia, IndiaMART, Maps)
     * Search engine scraping (Bing, DuckDuckGo, Yahoo)
     * Data validation & deduplication
     * Save to database
     * Polite delay (8-15s random)

3. After all cities/categories processed:
   - Wait 60 seconds
   - Start next cycle
